📋 Ask Felix - Bill Watch Tracker Instructions (No Code)
Project Overview
Build a conversational AI bill tracking app where users can communicate with "Felix" to manage bills, get reminders, and receive financial insights.

1. Project Foundation
Tell the agent to create:

A web application for bill tracking and management
An AI assistant named "Felix" that users can chat with
User authentication system with simple login
Database for storing user bills and conversation history
Notification system for bill reminders
Technology Stack to Request:

Web framework of agent's choice (React, Next.js, or similar)
PostgreSQL database using Replit's built-in database
AI integration using OpenAI or Perplexity API
SMS notifications using Twilio
Email notifications capability
2. Database Structure Requirements
Tell the agent you need these data tables:

Users Table:

User ID (primary key)
Name, phone number, email address
Account creation date
Bills Table:

Bill ID (primary key)
User ID (foreign key)
Bill name, amount, due date
Payment frequency (monthly, weekly, yearly)
Category (utilities, rent, credit cards, etc.)
Status (pending, paid, overdue)
Creation date
Conversations Table:

Conversation ID (primary key)
User ID (foreign key)
User message and AI response
Timestamp
Notifications Table:

Notification ID (primary key)
User ID and Bill ID (foreign keys)
Notification type (reminder, overdue, confirmation)
Sent date and status

Tell the agent Felix should handle:

Understanding natural language bill commands
Adding bills from conversational input
Providing bill summaries and insights
Answering questions about payment schedules

Helping categorize and organize bills
Example conversations Felix should understand:

"Add my electric bill for 120 dollars due on the 15th"
"What bills do I have this week"
"Mark my rent as paid"
"Remind me about my credit card payment"
"Show me my monthly expenses"
